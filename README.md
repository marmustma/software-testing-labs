# Тестирование программного обеспечения — лабораторные работы

Туманова Мария, группа 231-335, Московский Политех.

| Папка | Работа |
|-------|--------|
| `lab1` | Калькулятор — объект ручного тестирования (тест-план, чек-лист, тест-кейсы) |
| `lab2` | Todo List с намеренными дефектами — объект ad-hoc тестирования и баг-репортов |
| `lab3` | Первые UI-автотесты: Selenium WebDriver + pytest (стенд со страницей логина на Flask) |
| `lab4` | Page Object Pattern: позитивные и негативные сценарии контактной формы |
| `lab5` | Тестирование REST API: коллекция Postman и автотесты на requests + pytest |
| `lab6` | Модульные тесты класса `Calculator` (pytest, параметризация, исключения) |
| `lab7` | Android-приложение «Заметки», Appium-тест и чек-лист мобильного тестирования (запуск на эмуляторе в GitHub Actions) |
| `lab8` | Нагрузочное тестирование API с k6 |

Автотесты запускаются автоматически в GitHub Actions при каждом push в ветку `main`
(`.github/workflows/run-tests.yml`).

Локальный запуск:

```bash
pip install -r requirements.txt
cd lab6 && pytest -v
```
